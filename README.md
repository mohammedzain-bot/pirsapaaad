# PIRSAPAAAD Cream Unisex — Official Ecommerce Website

Premium, modern, fully responsive, and mobile-friendly ecommerce website for cosmetics brand **PIRSAPAAAD** (Unisex Cosmetics & Personal Care).

---

- **Brand Name**: PIRSAPAAAD
- **Category**: Unisex Cosmetics & Personal Care

  2. PIRSAPAAAD Whitening Beauty Cream (35g Starter Pack) — ₹499

  4. PIRSAPAAAD Nourishing Lip Balm (10g) — ₹249

---

## 🚀 Features

- **Mobile-First Experience**: Optimized 2-column product grid on mobile with bottom sticky navigation.
- **Hero Section**: Framed showcase box featuring official PIRSAPAAAD advertising poster and direct WhatsApp/Phone order shortcuts.
- **Interactive Cart & Coupons**: Free shipping progress indicator, discount coupons (`GLOW10`, `FIRSTBUY`, `PIRSA100`), slide-over drawer and cart page.
- **Checkout & Indian Payments**: Auto PIN code lookup for Indian cities/states, UPI (GPay, PhonePe, Paytm, QR scan simulation), Cash on Delivery, and Cards.
- **Order Tracking & Confirmation**: Order ID generation, printable receipts, celebratory confetti, and live tracking timeline.
- **Admin Dashboard**: Live revenue metrics, order status management, and complete product catalog CRUD.
- **WhatsApp Integration**: Direct ordering on WhatsApp (+91 7034044664) with pre-filled order messages.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite, TypeScript, Tailwind CSS, Lucide React, Canvas Confetti
- **Backend**: Node.js, Express, CORS
- **Storage**: JSON/SQLite persistent database

---

## 📦 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run both frontend and backend concurrently
```bash
npm run start
```
- Frontend: `http://localhost:5173`
- Backend API: `http://localhost:5001`

### 3. Build for production
```bash
npm run build
```
